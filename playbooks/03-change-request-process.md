# Change request process

The roadmap's immune system. The spec is explicit: client change requests get
captured, assessed, and prioritised — not handled as ad hoc custom work. This
process is how a client "quick tweak" becomes either roadmap work, paid scope,
or a polite no — visibly, and without souring the relationship.

## Flow

```
Intake → Assess → Decide → (Schedule | Decline | Park) → Communicate
```

1. **Intake.** Anyone (client call, founder chat, support ticket) → a Change
   Request work item within one working day. The requester never has to fill
   in a form — you do the capture; they get a reference number.
2. **Assess** (you, within 3 working days, pulling in founders as needed) —
   fill the assessment fields below.
3. **Decide** (product founder, at weekly delivery review — not in the
   client meeting): accept onto roadmap, accept as chargeable custom work,
   decline, or park with a revisit date.
4. **Communicate** the decision and timeline to the requester within a day of
   deciding. A fast, reasoned no beats a slow maybe.

## Assessment fields (straight from the spec's criteria)

| Field | Question it answers |
| ----- | ------------------- |
| Business value | What does the requester gain? Blocking their go-live, or nice-to-have? |
| Strategic value | Does this serve one client or many? Does it advance the product thesis? |
| Complexity | Technical founder's S/M/L + any architecture implications |
| Delivery risk | What does it displace? Regression surface? Compliance touch-points? |
| Roadmap fit | Aligned, adjacent, or off-roadmap (off-roadmap ⇒ custom-work conversation) |

## Guardrails

- **No verbal commitments in client meetings.** The honest line: "Good ask —
  I'll have it assessed and get you an answer by <date>." This protects the
  founders most of all.
- **One-client asks default to off-roadmap.** They need explicit strategic
  justification (or commercial terms) to displace roadmap work.
- **Emergency lane:** a genuine go-live blocker skips the weekly cadence —
  same fields, same decision-maker, 24-hour turnaround, logged the same way.
- **Every decline is logged with its reason.** Declined CRs are roadmap
  research: three clients asking for the same thing is a signal, and the log
  is where you see it.
